# Third-party sources and runtime dependencies

PCB RouteLab's release adapters, original research modules and generated examples use the root MIT license. Third-party notices remain applicable to their respective files.

| Component | Distribution in this repository | Attribution / license |
|---|---|---|
| KiCadRoutingTools | Python runtime and Rust source under `src/pcb_routelab/_assets/krt` | Copyright 2026 drandyhaas; MIT, preserved in that directory and `licenses/KiCadRoutingTools-MIT.txt` |
| DeepSeek Harness | Optional pinned SDK/runtime installed separately; framework source/binaries are not vendored | MIT notice in `licenses/DeepSeek-Harness-MIT.txt`; SDK/runtime lock in `requirements-harness.lock.txt` |
| KiCad | External application and native Python bindings; not bundled | Install separately; its own license applies |
| NumPy / SciPy / Shapely | Installed separately with exact versions | Their distribution licenses apply; not relabelled as project-owned code |
| Rust dependencies | Fetched by Cargo; exact versions/checksums in Cargo.lock | Individual package license metadata in `licenses/rust-dependencies.json` |

`source-origins.json` records original relative source labels and hashes for copied files. `source-lock.json` binds the released source. The bundled KRT is the local research snapshot identified by those hashes; a version string does not assert that it is an unmodified upstream Git commit. Routing algorithms, original congestion mechanisms and native DRC are upstream capabilities. This release adds packaging, runtime configuration and acceptance protections; it does not claim to invent those algorithms.

No third-party PCB designs, model transcripts, credentials, historical research datasets or compiled engine binaries are included. The small PCB fixture is generated by `scripts/make_example.py` and is provided under the root MIT license. Research results are project-authored aggregate summaries; they do not redistribute source board files.
